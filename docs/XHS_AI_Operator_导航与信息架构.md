本文档把产品 **八步主流程** 收进侧栏分组，借鉴「首页 + 可折叠分组」的布局，菜单名称与能力边界以本机小红书单账号运营为准，不照搬外部 Creator 产品词条。

## 1. 侧栏总览

```text
首页

热点 ▾
  ├ 当日热点
  └ 新闻爆点

创作 ▾
  ├ 一键成文（内嵌六步向导）
  └ 一键成图

工具 ▾
  ├ 小红书内容提取
  ├ 视频下载
  ├ 复盘
  └ 数据跟踪

资源 ▾
  ├ 成品库
  ├ 爆款库
  ├ 书架
  └ 灵感库

设置 ▾
  ├ 账号配置
  ├ 模型配置
  └ 系统设置
```

底栏仅保留运营约束提示（例如「人工确认后发布」），不再重复「设置」入口。

---

## 2. 与 PRD 八步主流程的对应

PRD 规定：上一步没有合格产物时，下一步不开始；第 8 步确认后的知识供下一轮第 2、3 步使用。

| PRD 八步 | 侧栏主要入口 | 说明 |
| --- | --- | --- |
| 1 热点与素材发现 | **热点** | 当日热点、新闻爆点进同一素材池，状态可追溯 |
| 2 热点分析与账号适配 | **创作 → 一键成文 → 选题** | 与第 3 步在向导前几屏连续完成 |
| 3 选题决策与内容策划 | **创作 → 一键成文 → 选题** | 候选选定与方案后再进入写作 |
| 4 图文内容生产 | **创作 → 一键成文 → 写作 / 去 AI 味** | 草稿非终稿；人工改稿 |
| 5 视觉设计与卡片生成 | **创作 → 一键成文 → 配图 / 排版**；**一键成图** | 成图入口只做视觉，不跳过文案底线 |
| 6 人工审核与发布 | **创作 → 一键成文 → 发布** | 确认绑定当前版本 |
| 7 数据跟踪与效果复盘 | **工具 → 数据跟踪、复盘** | 只用本账号指标 |
| 8 知识沉淀与策略优化 | **资源** | 待确认 → 人工确认 → 可检索 |

## 3. 分组说明

### 3.1 首页（原「工作台」）

**目的：** 对话入口 + 任务总览 + 八步快捷链接（与 PRD F9 助手一致）。

| 能力 | 要求 |
| --- | --- |
| 提问 | 先检索已确认知识，再调本目录配置的模型；无模型时给摘录与来源 |
| 任务 | 展示当前 workflow 停在哪一步、等待输入或确认 |
| 推荐问法 | 选题方法、失败采集等，回答带「打开这一步」链到具体功能 |

**路由（规划）：** `/`

**当前代码（约 2026-11-21）：** 侧栏仍写「工作台」，主体能力已在 `/`。

---

### 3.2 热点（原「发现」）

**目的：** 只做「发现」，不做选题与成稿（对应 PRD §7.1）。

| 菜单 | 含义 | 数据来源 | 验收 / 门禁 |
| --- | --- | --- | --- |
| **当日热点** | 今天可查的小红书公开热点与榜单 | `hot_daily`、`daily_top`（验证通过前关闭） | 至少 5 条真实标题 + 可打开链接；失败不进选题 |
| **新闻爆点** | 跨平台或人工搬运的「爆点」线索 | 人工链接 / 截图说明 / 文案；其他平台自动采集第一版不做 | 与素材池同规则：失败可见、mock 不算成功 |

两页底层共用 **素材池**（合并链接、状态、失败原因），列表可按 `kind`、来源或标签筛选，避免做两套数据。

**路由（规划）：** `/hot/today`、`/hot/news`（或 query：`/materials?view=today`）

**当前代码：** 合并为 `/materials`「素材池」。

---

### 3.3 创作（合并原「选题与成稿」「发布与沉淀」中的制作段）

**目的：** 从适配到发布的 **图文闭环**；与 PRD §7.2～7.6 一致。

#### 3.3.1 一键成文（六步向导）

向导顶栏固定六步（与用户提供的交互稿一致），每一步对应 PRD 能力，**不能跳步**（缺前置产物则该步只读或提示回退）。

| 向导步 | 用户看到什么 | 对应 PRD | 主要产物 / 动作 |
| --- | --- | --- | --- |
| **1 选题** | 5 个候选 + 适配报告（事实 / 知识库 / 判断） | §7.2、§7.3 | 选定一条；可改写、否决 |
| **2 写作** | 按模板生成 3～6 页草稿 | §7.4 | 标题、摘要、标签、分页文案 |
| **3 去 AI 味** | 在草稿上人工改口吻（可唤起首页对话辅助，不自动覆盖已确认版） | §7.4、§8 | 版本递增时清除确认 |
| **4 配图** | 生成封面与各页卡片图 | §7.5（视觉前半） | SVG 卡片、相对路径 |
| **5 排版** | 字数 / 标题 / 溢出检查 + 审核勾选单 | §7.5、§7.6 | `review_json`、七项清单 |
| **6 发布** | 预览、确认版本、调用 MCP 发布（未配置则记失败） | §7.6 | 发布日志、版本绑定 |

**状态机：** 与现有 `workflow` / `notes.publish_status` 对齐；`WAITING_INPUT` / `WAITING_APPROVAL` 等在向导右侧或底部常显。

**路由（规划）：** `/create/article`（单页应用内 `step=1..6`，深链可带 `note_id`）

**当前代码：** 分散在 `/topics`、`/notes/:id`、`/publish`；尚无统一向导壳。

#### 3.3.2 一键成图

**目的：** 对 **已有草稿** 只做视觉（PRD §7.5），不替代选题与写作。

- 选择当前笔记 → 生成 / 重生封面与各页图 → 展示检查结果。  
- 重新出图导致版本变更时，按 PRD 作废原确认。

**路由（规划）：** `/create/visual`

**当前代码：** `/covers`「封面与卡片」。

---

### 3.4 工具

**目的：** 与「创作」主链并行的辅助能力；采集类能力 **验证通过前保持关闭**，UI 可点但结果为 `source_unavailable` / 失败状态，不造笔记。

| 菜单 | 含义 | 对应 PRD / 采集 | 备注 |
| --- | --- | --- | --- |
| **小红书内容提取** | 关键词搜索、笔记详情、评论（可选） | F1.7、`media_crawler` | 无登录绕过 |
| **视频下载** | 选定笔记媒体归档到 `data/xhs/` | F1.6、`xhs_downloader` | 外部进程，不内置源码 |
| **复盘** | 写复盘稿、案例、周期报告；确认前不可检索 | §7.7 | 观察 / 假设标注 |
| **数据跟踪** | 录入曝光、阅读、点赞、收藏、评论、涨粉；本账号排行 | §7.7 | 不用他人爆款当本账号结论 |

**路由（规划）：** `/tools/extract`、`/tools/download`、`/tools/review`、`/tools/metrics`

**当前代码：** 复盘与指标在 `/reviews`；采集探针在素材池表单。

---

### 3.5 资源（原「发布与沉淀」中的沉淀段 + 知识库）

**目的：** 可复用资产的 **浏览与入库**（PRD §7.8），不是创作流水线。

| 菜单 | 存放什么 | 状态 | 检索 |
| --- | --- | --- | --- |
| **成品库** | 本账号已发布或已定稿待确认的笔记 | 按 `publish_status`、版本 | 列表 + 打开笔记 |
| **爆款库** | 本账号高表现笔记、已确认 **案例** | `approved` 案例 md | 指标排序 + 知识条目 |
| **书架** | 已确认 **运营方法、策略、复盘** | `status: approved` | 向量 / 关键词 |
| **灵感库** | 选题方法、待确认文稿、`inbox/pending` | `pending` 与 `approved` 分开展示 | 仅 approved 进问答检索 |

写入路径不变：复盘 / 案例 / 周期报告先 `pending`，用户确认后进入书架或爆款库并可被检索。

**路由（规划）：** `/library/works`、`/library/hits`、`/library/shelf`、`/library/ideas`

**当前代码：** 知识库 `/knowledge`；笔记列表混在复盘页；待确认靠复盘页按钮。

### 3.6 设置（不变）

| 菜单 | 内容 |
| --- | --- |
| 账号配置 | 读 `account.yaml`：定位、读者、类型、语气（定位可「待确定」） |

**路由：** `/start`、`/settings`、`/system`（已实现）。

## 5. 体验规则（继承 PRD §8）

1. 向导中当前步未完成时，后续步展示为禁用或只读说明，不出现「假完成」。  
2. 热点页采集失败、mock、需登录：列表可见，**不得进入一键成文的选题步**。  
3. 一键成文与一键成图共用同一 `note_id` / `version`；改稿、重图使确认失效。  
4. 工具里的采集与下载失败一次记录一次，不无限重试。  
5. 资源库中 `pending` 内容在首页问答里不得被当成已确认知识引用。

## 6. 落地顺序建议

1. **IA 改名与分组**：首页、热点、创作、工具、资源、设置（仅导航与页标题，路由可先不变）。  
2. **一键成文向导壳**：六步顶栏 + 嵌入现有 topics / note / publish API。  
3. **热点拆分**：当日热点 / 新闻爆点视图过滤素材池。  
4. **资源四库**：成品库、书架先挪数据；爆款库、灵感库接确认流。  
5. **工具四页**：从素材探针迁出；采集 PoC 通过后再默认展示「可用」态。
