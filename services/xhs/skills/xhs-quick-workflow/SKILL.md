# 一键成文工作流（对齐 xhs-ai-workflow 思路）

1. 选题/主题明确 → 2. 策划分页 → 3. LLM 出草稿 → 4. 人工改稿（本步必经）→ 5. 去 AI 味 → 6. 配图 → 7. 排版检查 → 8. 确认发布。

本工作台「一键成文」只自动完成 1–3；4 之后必须人工确认。协作成文是另一条逐步确认路径，不要混用。
